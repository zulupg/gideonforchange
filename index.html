Free Cloud Sync (Firebase Firestore)

Keeps your moved markers, added places, polygons and population sheet online, so any PC that connects sees the same data. Free Spark plan: 1 GiB storage, 50K reads & 20K writes per day, no credit card.

Connection code: use this on your other PC
Treat it like a password: anyone who has it can read and change your synced data.
First-time setup (once, about 5 minutes)
  1. Go to console.firebase.google.com → Add project (turn Google Analytics off).
  2. Build → Authentication → Get started → Anonymous → Enable.
  3. Build → Firestore Database → Create database (any region, production mode), then Rules: paste the rules below and Publish.
  4. Project settings → Your apps → Web (</>) → register app → copy the firebaseConfig block.
  5. Paste it below and press Connect. Your edits upload automatically.
On another PC: open this file → ☁ Backup → paste the connection code → Connect.
Firestore security rules to paste (step 3) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
